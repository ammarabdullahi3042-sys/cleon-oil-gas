CLEON Company Profile

This folder contains five-page dark and white profile editions in PDF and editable Microsoft Word DOCX formats.

The assets subfolder contains the original CLEON logo, an optional light-surface logo derivative, the user-supplied refinery photograph, and soft-edge image versions used on the profile covers. The central photograph is unchanged and uncropped; only the outer edges fade into each page background.

The Technology section describes the existing website and distinguishes intended investor tracking and timely update features from secure, live integrations that require implementation. Management contact details are identified as unconfirmed because no address, phone number or email was supplied.
